Data Analysis · 2026

TripAdvisor Reviews and Public Data for Korean Tourism Recommendations

Built a tourism analytics and recommendation concept by combining multilingual TripAdvisor reviews with public datasets on lodging, transportation, and local infrastructure. The project explores how sentiment, topic modeling, geospatial analysis, and congestion signals can support more personalized and sustainable travel recommendations.

LLM-Based Serialization for Representation Learning in Recommender Systems

Proposed an LLM-based content serialization framework for recommender systems. The work focuses on reconstructing heterogeneous and incomplete item data into semantically consistent representations to improve rating prediction and personalized recommendation.
